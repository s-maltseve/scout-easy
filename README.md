# SCOUT-EASY

SCOUT-EASY — лёгкая self-hosted панель мониторинга и администрирования Linux-сервера. Она показывает активные SSH-сессии, историю входов, Fail2ban, сетевые соединения и трафик, процессы, системные ресурсы, а также всех локальных Linux-пользователей с их группами и уровнем доступа.

## Возможности

- активные SSH-сессии с пользователем, IP, TTY и временем начала;
- успешные и неудачные SSH-входы с точным временем события;
- просмотр, добавление и удаление IP в Fail2ban;
- отключение выбранной SSH-сессии;
- текущий и накопленный сетевой трафик;
- трафик по TCP-соединениям и процессам;
- список процессов с фильтрацией и сортировкой;
- полный список Linux-пользователей, UID/GID, shell, домашний каталог и группы;
- отметка административных, системных и обычных пользователей;
- вход по логину, паролю и одноразовому 6-значному коду 2FA;
- серверная сессия в защищённой HttpOnly-cookie;
- ограничение попыток входа;
- HTTPS через Nginx и Let’s Encrypt.

## Требования

- Debian 12+ или Ubuntu 22.04+;
- root или sudo;
- Python 3.11+;
- для публичного HTTPS — домен с A/AAAA-записью на сервер и открытые порты 80/443.

## Установка

```bash
git clone https://github.com/s-maltseve/scout-easy.git
cd scout-easy
sudo bash install.sh
```

Установщик:

1. устанавливает зависимости;
2. копирует приложение в `/opt/scout-easy`;
3. создаёт systemd-службу;
4. создаёт случайный логин и сложный пароль;
5. создаёт секрет двухфакторной аутентификации;
6. показывает QR-код для Aegis, 2FAS, Bitwarden или Google Authenticator;
7. по запросу настраивает Nginx и сертификат Let’s Encrypt.

После установки сохраните выведенный пароль и отсканируйте QR-код. Сам пароль в открытом виде на сервере не хранится: сохраняется только стойкий scrypt-хеш.

## Вход

Откройте адрес панели, например:

```text
https://scout.example.com
```

Введите:

- случайный логин, выданный установщиком;
- пароль, выданный установщиком;
- текущий 6-значный код из приложения-аутентификатора.

Сессия автоматически завершается после периода бездействия. По умолчанию — 30 минут.

## Где посмотреть логин и повторно показать QR-код 2FA

```bash
sudo scout-easy
```

Выберите пункт:

```text
1) Показать логин и QR-код 2FA
```

Пароль посмотреть нельзя, поскольку он хранится только в виде хеша. Его можно сбросить через тот же менеджер.

## Смена пароля

```bash
sudo scout-easy
```

Выберите:

```text
2) Сбросить пароль
```

Можно задать пароль вручную или оставить поле пустым, чтобы SCOUT-EASY создал новый случайный пароль.

## Пересоздание 2FA

```bash
sudo scout-easy
```

Выберите:

```text
3) Пересоздать 2FA
```

Все старые коды перестанут работать. Затем выберите пункт 1 и отсканируйте новый QR-код.

## Fail2ban

В блоке **Fail2ban** отображаются все jail и заблокированные IP.

Для блокировки:

1. выберите jail;
2. укажите IPv4 или IPv6;
3. нажмите **Добавить в бан**.

Для разблокировки нажмите крестик рядом с IP. Все изменения требуют активной авторизованной сессии с 2FA и защищены проверкой источника запроса.

## Пользователи Linux

Раздел **Все пользователи Linux** показывает:

- имя пользователя;
- UID и GID;
- тип: администратор, системный или обычный;
- основную и дополнительные группы;
- shell;
- разрешён ли интерактивный вход;
- домашний каталог.

Администраторами считаются `root` и пользователи групп `sudo`, `wheel`, `admin` или `root`.

## Обновление

```bash
cd ~/scout-easy
git pull --ff-only origin main
sudo bash install.sh --non-interactive
```

Обновление сохраняет:

- логин;
- хеш пароля;
- настройки 2FA;
- параметры доступа;
- существующую конфигурацию Nginx и сертификат.

Проверка версии:

```bash
curl http://127.0.0.1:8765/api/health
```

## Управление службой

```bash
sudo systemctl status scout-easy
sudo systemctl restart scout-easy
sudo journalctl -u scout-easy -n 100 --no-pager
```

Или используйте меню:

```bash
sudo scout-easy
```

## Конфигурация

Файл:

```text
/etc/scout-easy/scout-easy.env
```

Основные параметры:

```env
SCOUT_ACTIONS_ENABLED=true
SCOUT_BIND_HOST=127.0.0.1
SCOUT_BIND_PORT=8765
SCOUT_SESSION_MINUTES=30
SCOUT_LOGIN_ATTEMPTS=5
SCOUT_LOGIN_WINDOW_SECONDS=600
SCOUT_SECURE_COOKIE=true
```

Права файла должны оставаться `600`.

## Безопасная публикация

Рекомендуемая схема:

```text
Интернет → HTTPS/Nginx → 127.0.0.1:8765
```

Не открывайте порт `8765` напрямую. Для максимальной защиты дополнительно ограничьте доступ через VPN или allowlist IP.

## Удаление

```bash
sudo bash uninstall.sh
```
